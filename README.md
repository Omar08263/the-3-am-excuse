One line, in the voice of a hardware wallet refusing to sign a transaction at 3 AM: the sleep-deprived owner is the threat model, and the wallet is the only one still thinking clearly.

## Run it

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (one line, 1–200 characters, UTF-8, mode 0644), guarded and self-verified after writing.
